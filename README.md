# 🕵️‍♂️ Sherlook

**پروژه مدیریت هوشمند شبکه، خودکارسازی سرور و گره‌های ارتباطی**

`Sherlook` یک ابزار پیشرفته، متن‌باز و بهینه‌شده برای مدیریت خودکار گره‌های شبکه، پراکسی‌ها و پیکربندی‌های پیچیده سرور است. این ابزار با تمرکز بر پایداری بالا، مصرف بهینه منابع و اتوماسیون کامل طراحی شده است تا در محیط‌های حساس بهترین عملکرد را ارائه دهد.

---

## 🌟 ویژگی‌های برجسته

* 🛡️ **سیستم خودترمیمی (Auto-Heal):** شناسایی آنی گره‌های معیوب و جایگزینی خودکار.
* 📉 **بهینه‌سازی منابع:** کاهش چشمگیر عملیات I/O روی دیسک جهت افزایش طول عمر حافظه سرور.
* ⚡ **مدیریت تایم‌اوت هوشمند:** پیکربندی دینامیک برای جلوگیری از اتلاف منابع روی اتصالات کند.
* 🛠️ **نصب و راه‌اندازی سریع:** اسکریپت نصب یک‌پارچه با قابلیت اجرا تنها با یک دستور.
* ⚙️ **شخصی‌سازی‌پذیری بالا:** ساختار ماژولار با امکان ویرایش آسان متغیرها.

---

```bash
wget -qO- https://raw.githubusercontent.com/SherlookHolmz/multi/main/sherlook.sh | bash

```

## 📋 راهنمای استفاده و پیکربندی

### ۱. ویرایش فایل تنظیمات

برای باز کردن و ویرایش تنظیمات داخلی اسکریپت، از دستور زیر استفاده کنید:

```bash
nano sherlook.sh

```

### ۲. متغیرهای کلیدی قابل تنظیم

در بخش تنظیمات اسکریپت می‌توانید پارامترهای زیر را بهینه‌سازی کنید:

* `MAX_NEWNYM_TRIES`: تعداد دفعات تلاش مجدد برای ساخت مدار جدید پیش از محدودسازی IP.
* `TIMEOUT_CONNECT`: حداکثر زمان انتظار برای برقراری اتصال اولیه.
* `AvoidDiskWrites`: فعال‌سازی حالت کاهش نوشته‌های دیسک (مقدار پیش‌فرض: `1`).
